# Planificador de Tareas Web

Proyecto individual desarrollado durante el Bootcamp Full Stack Java de Generation Colombia.

## Descripción

Aplicación web para crear, visualizar y gestionar tareas.

## Sprint 1

En este sprint se trabajará en:

- Implementación del wireframe con HTML y Bootstrap.
- Creación del componente de tarjeta de tarea.
- Construcción de la lista de tareas.
- Validación de los campos del formulario.

## Tecnologías

- HTML5
- CSS3
- Bootstrap
- JavaScript

## Estado del proyecto

En desarrollo.
